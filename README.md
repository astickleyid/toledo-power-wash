# Toledo Power Wash

Marketing website for **Toledo Power Wash** — commercial & residential power washing in Toledo, Ohio.  
Owner: **Austin Stickley**.

## Why this name

Local SEO: people search “Toledo power wash / power washing / pressure washing.”  
City + service is the highest-intent pattern for Google Business Profile and organic search.

## Run locally

```bash
cd /Users/astickley/development/projects/toledo-power-wash
npm install
npm run dev
```

Open: http://localhost:3007

## Deploy (Vercel)

```bash
cd /Users/astickley/development/projects/toledo-power-wash
vercel
```

Set env (optional):

```
NEXT_PUBLIC_SITE_URL=https://toledopowerwash.com
```

Buy **toledopowerwash.com** and attach it in Vercel.
